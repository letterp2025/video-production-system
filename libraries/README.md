# Visual libraries

This directory contains the public, reusable visual libraries. Every entry here is intended for public distribution under the repository's code and documentation licenses, except for third-party material explicitly identified under its own terms.

| Library | Contents | Index |
|---|---|---|
| Visual elements | Reusable graphic and typographic building blocks, with style variants | [Open the library](visual_elements_library/README.md) |
| Visual animations | Reusable motion recipes and their tool-specific implementations | [Open the library](visual_animations_library/README.md) |
| Visual references | Public methods and templates for studying visual references; only cleared studies may be added | [Open the guide](visual_reference_library/README.md) |

Private channel work stays in its internal workspace. Do not put private entries in this directory and rely on `.gitignore` to hide them.

Screenshots, downloads, renders, native editing projects, fonts, and other media are local working files. They are ignored by Git and are not part of the public library release.
