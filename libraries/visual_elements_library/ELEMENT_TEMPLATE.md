## Style variants

The full folder basename is the stable element ID and remains the same across style variants. Assign each distinct visual treatment an ID scoped to this element (`STY-01`, `STY-02`, ...); refer to the pair as its full identity, for example `ELM-pixel-cell-grid / STY-01`. Put the style name before the style ID in an optional folder, such as `styles/retro-STY-01/`. Keep the folder ID stable through routine title or description changes.

Record treatments that keep the element's structure and purpose. Retro, minimal, and high contrast are examples only; the style list is open-ended.
