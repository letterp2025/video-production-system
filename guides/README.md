# Production Guides

These guides describe reusable planning and analysis methods for motion-led video projects. They are tool-flexible and independent of any one channel or product. Tool setup and command details remain in each tool's guide.

## Guides

- [EffectCraft Guide](EFFECTCRAFT_GUIDE.md) — use AI prompts, MCP, or code-authored project data to build EffectCraft projects, review them in the GUI, and choose a render workflow.
- [Video production workflow](VIDEO_PRODUCTION_WORKFLOW.md) — move from a viewer-facing idea through planning, production, review, and delivery.
- [Storyboard and visual planning](STORYBOARD_AND_VISUAL_PLANNING.md) — connect story beats to scenes, visible elements, and animation.
- [Video formats and visual treatments](VIDEO_FORMATS_AND_TREATMENTS.md) — distinguish story structure from visual style and compare combinations.
- [Reference video analysis](REFERENCE_VIDEO_ANALYSIS.md) — use broad and dense frame sampling to identify visual elements and map selected motion.
- [YouTube growth](YOUTUBE_GROWTH_GUIDE.md) — focus a channel promise, make viewer value concrete, review performance, and interpret monetization guidance carefully.
- [YouTube script writing](YOUTUBE_SCRIPT_WRITING_GUIDE.md) — turn creator notes into speakable scripts while preserving voice and reviewing narration in segments.
